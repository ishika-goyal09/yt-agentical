# Generative AI Chatbot 🤖

A beginner-friendly Generative AI chatbot built using Node.js, LangChain, and Mistral AI. This project explores the fundamentals of working with Large Language Models (LLMs), prompt handling, conversation history, and streaming AI responses.
The chatbot uses Mistral AI's mistral-small-latest model through LangChain and provides an interactive command-line chat experience.

📌 Overview

This project was created as part of my journey to learn Generative AI and LLM application development.
The application allows users to interact with an AI assistant through the terminal. The chatbot maintains conversation history during the session, allowing the AI to understand previous messages and provide context-aware responses.
The project also demonstrates how to securely manage API credentials using environment variables.
